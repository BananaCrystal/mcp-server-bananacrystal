# MCP Discovery Networks & Registries Listing Guide

This repository contains all official manifests and configurations for publishing `@bananacrystal/mcp-server` across major AI discovery networks.

## Manifest Index
* **The Official MCP Registry:** `server.json` (root)
* **Smithery.ai:** `smithery.yaml` (root)
* **Remote MCP / AI Connectors:** `manifests/remote-mcp.json`
* **Windows On-device Agent Registry (ODR):** `manifests/windows-odr-manifest.json`
* **JFrog MCP Enterprise:** `manifests/jfrog-mcp-descriptor.yaml`
* **Blotato Hub:** `manifests/blotato-manifest.json`
* **Meta Muse:** `docs/meta-muse-integration.md`
